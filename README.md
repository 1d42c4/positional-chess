# Positional Chess

**24 illustrated topic lessons + a study guide · 25 PDFs · 100 pages**

**[Read the collection on GitHub Pages](https://1d42c4.github.io/positional-chess/)** · [Download all PDFs](downloads/positional-chess-pdfs.zip) · [Start with the study guide](pdfs/00_Start_Here.pdf)

Every four-page lesson contains a positional concept, worked diagrams, reasoning for both sides, a practice position, explained answers, a changed-position question, and a drill for your own games. The olive-and-cream boards use dark Cburnett vector pieces.

## Study

Read the guide first. Study four topics per week, solve each exercise before opening its answers, and repeat missed questions the next day and the following week. The PDFs contain a notation key and position codes (FEN) for recreating the practice boards.

The examples are original constructed teaching positions, not attributed master games. All 48 starting positions and 127 sample plies were checked for legal position status and canonical legal notation with python-chess. The lines illustrate plans and explicitly labeled mistakes; they are not claims of unique engine-best moves.
